# Antecedentes — Semana 3

Los sistemas de información estudiantil se han utilizado para apoyar procesos como registro, matrícula, calificaciones y mantenimiento de expedientes académicos. Un antecedente documentado describe el uso de un Student Information System en la Universidad de Utrecht para apoyar, entre otros procesos, la preparación de horarios, registro y mantenimiento del historial académico.

La ingeniería de requisitos también establece la necesidad de identificar, documentar y gestionar requisitos durante el ciclo de vida del software. La norma ISO/IEC/IEEE 29148:2018 define procesos y productos relacionados con la ingeniería de requisitos y características de los requisitos.

En este proyecto, estos antecedentes sustentan la decisión de separar el análisis del problema, los requerimientos y el diseño de clases antes de ampliar la implementación.
