# Diagrama de Ishikawa — Semana 3

**Efecto:** dificultades para gestionar las matrículas de forma organizada, rápida y confiable.

- **Procesos:** registro manual; pasos repetidos; falta de validaciones.
- **Personas:** errores de digitación; desconocimiento del estado de cupos.
- **Tecnología:** herramientas no integradas; ausencia de sistema centralizado.
- **Información:** datos duplicados; registros incompletos; dificultad de consulta.
- **Entorno:** alta demanda en períodos de matrícula; tiempo limitado.
