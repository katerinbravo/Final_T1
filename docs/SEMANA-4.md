# Semana 4 — Requerimientos

## Objetivo
Definir las necesidades funcionales del sistema.

## Requerimientos principales
1. Registrar estudiantes.
2. Registrar cursos.
3. Consultar estudiantes.
4. Consultar cursos.
5. Crear matrículas.
6. Consultar matrículas.
7. Validar datos requeridos.
8. Gestionar cursos prerrequisito.
9. Evitar registros inconsistentes.
10. Mantener información organizada.

## Historias de usuario
- Como administrador, quiero registrar estudiantes para disponer de su información.
- Como administrador, quiero registrar cursos para mantener la oferta académica.
- Como estudiante, quiero realizar una matrícula para registrar mis cursos.
- Como administrador, quiero consultar matrículas para verificar los registros.
