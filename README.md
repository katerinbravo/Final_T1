# Sistema de Gestión de Matrículas Académicas

Proyecto académico de Programación Orientada a Objetos.

## Organización del trabajo
Este repositorio corresponde a un desarrollo individual. Se utiliza GitHub para registrar el avance, organizar las versiones y documentar los entregables.

## Semanas
- Semana 3: análisis del problema y fundamentos de POO.
- Semana 4: requerimientos e historias de usuario.
- Semana 5: análisis del proceso y modelo de clases UML.

## Ramas
- `main`: versión estable.
- `develop`: integración del desarrollo.
- `feature/*`: trabajo específico por entregable.

## Proyecto
El sistema busca gestionar estudiantes, cursos y matrículas aplicando Programación Orientada a Objetos.
